# Supermarket Billing System

Python Tkinter frontend + SQLite SQL backend.

## Features
- Product management: add, edit, delete, search
- Billing/POS popup
- Barcode/product-code entry
- Cart and quantity validation
- Subtotal, tax, discount, total
- Cash payment and change
- Saves bills and bill items in SQLite
- Bill history with details
- Text receipt generation
- Dashboard

## Run
Python 3.10+ recommended.

    python main.py

No third-party packages are required. Tkinter and sqlite3 are from the Python standard library.
